# 健康トラッカー

体重管理と健康管理のために、毎日の体重・運動・食事・睡眠・水分・疲労度とストレスを記録するWebアプリです。
PCとスマホのブラウザで使います。

## このプロジェクトの目的

- 食事と運動のカロリー収支を毎日つかみ、体重管理に役立てる
- 記録を続けやすいよう、入力の手間を最小限にする
- 記録したデータを Claude に読ませて、週ごとの振り返りに使う

## 機能

| 画面 | できること |
|---|---|
| 記録 | 日付ごとに、カロリー収支・体重・運動・食事・睡眠・水分・疲労度とストレスを入力する |
| 直近7日 | 7日分の一覧と、体重の変化・収支の合計・平均値を見る |
| マイ食品 | 成分表にない市販品や外食の栄養表示を登録する |
| 設定 | プロフィール（身長・生年月・性別・普段の活動量）、運動のMETs、コップ1杯の量、データの書き出し |

### 計算のしかた

- **食事の栄養**：食材のグラム数 ×「日本食品標準成分表」の可食部100gあたりの値 ÷ 100。エネルギーを含む53項目を計算する
- **運動の消費カロリー**：METs × 体重（kg）× 運動時間（時間）
- **基礎代謝**：国立健康・栄養研究所の式（身長・体重・年齢・性別から推定）
- **1日の消費**：基礎代謝 × 普段の活動量 ＋ 運動の上乗せ分（METs から安静時の 1 を引いた分。基礎代謝との二重計上を避けるため）
- **収支**：摂取 − 消費

いずれも推定値です。1日ごとの値より、1週間単位の傾向を見るのに向いています。

## 使用技術

- HTML / CSS / JavaScript（ビルド不要。ライブラリは使っていない）
- Python（成分表・メッツ表をアプリ用データに変換するスクリプト）

## ファイル構成

```
index.html        画面の骨組み（記録・直近7日・マイ食品・設定）
style.css         見た目（スマホ幅が基準、ダークモード対応）
app.js            画面の表示・入力・保存
nutrients.js      栄養素の定義、成分表の読み込み、食材検索、栄養計算
body.js           METs、消費カロリー、基礎代謝、BMI の計算
foods.json        成分表をアプリ用に変換したデータ（2,538食品）
tools/
  convert_foods.py  成分表のExcel → foods.json
  extract_mets.py   メッツ表のPDF → 全活動のMETs一覧（body.js の値の確認用）
```

## 使い方

`index.html` をブラウザで開くと動きます（成分表 `foods.json` の読み込みには、ローカルサーバーか GitHub Pages が必要です）。

```bash
# ローカルで試すとき
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## データの保存

今はブラウザの localStorage に保存しています（端末ごとに別のデータ）。
PCとスマホで同じデータを使えるよう、非公開リポジトリ `health-data` に JSON で保存する同期機能を追加する予定です。

### 1日分の記録の形

```json
{
  "date": "2026-10-26",
  "body": { "weightKg": 72.4 },
  "exercise": [{ "type": "ウォーキング", "minutes": 30, "intensity": 2, "mets": 3.8, "kcal": 138 }],
  "steps": 8000,
  "meals": [{
    "time": "12:30", "kind": "昼食",
    "items": [{
      "name": "親子丼", "amount": "1人前",
      "ingredients": [{ "foodId": "11221", "name": "鶏もも肉（皮つき）", "grams": 80,
                        "nutrients": { "kcal": 152, "protein": 13.3 } }]
    }]
  }],
  "sleep": { "bedtime": "23:30", "wakeTime": "06:45", "napMinutes": 20 },
  "waterMl": 1200,
  "condition": { "fatigueWork": 3, "fatiguePrivate": 2, "stressWork": 4, "stressPrivate": 2, "memo": "" },
  "updatedAt": "2026-10-26T21:00:00+09:00"
}
```

記録を消した日は、データを消さずに「削除の印」を残します（PCとスマホの同期で、消したことを伝えるため）。

```json
{ "date": "2026-10-27", "deleted": true, "updatedAt": "2026-10-27T22:10:00+09:00" }
```

保存するデータには、データの形の版番号 `schemaVersion`（今は 1）がつきます。設計の詳細は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。

## データの更新手順

成分表やメッツ表が改訂されたときは、元のファイルを入手してスクリプトで作り直します（元のファイルはリポジトリに入れない）。

```bash
# 成分表（文部科学省のサイトの「第2章（データ）」のExcel）
python3 tools/convert_foods.py 成分表.xlsx foods.json

# メッツ表（PDF）。body.js の METS_DETAIL の値と照らし合わせる
pdftotext -layout メッツ表.pdf mets.txt
python3 tools/extract_mets.py mets.txt mets.json
```

## 出典

- 食品の栄養素：日本食品標準成分表（八訂）増補2023年（文部科学省）から引用
- 運動のMETs：改訂第2版『身体活動のメッツ(METs)表』成人版（2024年）
- 基礎代謝の推定式：Ganpule et al. (2007)（国立健康・栄養研究所の式）
- 普段の活動量の係数：日本人の食事摂取基準（2025年版）
- BMIの判定区分：日本肥満学会
